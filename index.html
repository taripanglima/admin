Mesej PGPM
Owner dan Super Admin boleh menghantar mesej peribadi. Klik ikon pada akaun untuk membuka chat. Dalam chat, ikon digunakan untuk lampiran. Klik kanan mesej sendiri untuk Edit, Padam untuk semua atau Padam untuk saya. Edit hanya boleh dibuat dalam 15 minit selepas dihantar.
Super Admin
Owner boleh melihat semua Super Admin. Owner dan Super Admin boleh menghantar mesej antara satu sama lain melalui ikon .
Portal ini menggunakan Supabase Auth + RLS/RPC. Jangan letakkan service-role key atau private VAPID key di frontend.
